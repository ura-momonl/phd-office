# 本地转录小窗口

双击 `D:\Zoom-recordings\Transcribe.lnk`。

1. 点击「选择录音…」，选已经停止、封存的 `.flac` 文件；也可以粘贴完整路径。
2. 点击「开始转录」，等待显卡、校验和转录；窗口显示实际日志，不提供虚构的百分比。
3. 完成后点击「打开文字稿」或「打开结果目录」。TXT、SRT、JSON 保存到音频旁边。

窗口程序：`D:\Zoom-recordings\quiet-recorder\transcription_ui.py`。
沿用同目录的 `auto_transcribe.py`，强制使用已缓存模型和 CUDA，自动识别语言。
不上传、不调用付费 API、不加开机自启，也不控制录音器。

原录音不改动；完整已有结果会跳过，部分已有结果会拒绝开始，不删除或覆盖。
关闭正在转录的窗口前会提醒：关闭窗口不取消任务，任务会继续后台完成。
如报错，可查看窗口日志或同名 `.transcribe.log`；原录音保留。重要句子须回听核对。
