# Workbench 语音输入

点发送键旁的麦克风小图标，允许网站使用麦克风，讲话后再点一次停止并转写。
也可在聊天页按下并松开 Ctrl＋Shift 开始／停止；按住不连续触发，Ctrl＋Shift＋V 等其他组合不触发。
这是页面快捷键，不是后台全局热键；Windows 可能同时切换输入法，本功能不改系统快捷键设置。
识别文字追加到当前草稿，不覆盖已有文字、不自动发送。语言由模型自动识别，聊天框不提供语言切换。
录音最长两分钟；取消或切换对话不会把迟到的转写填到另一个对话。
取消正在进行的转写只取消等待及填入，已经开始的 GPU 运算可能继续完成。

仅浏览器麦克风采集，不录系统声音；音频只传到本机 Workbench。
临时音频在转写结束后删除，不进入消息附件或会议录音目录，不调用付费 API。
后台首次使用时加载模型，闲置十分钟释放进程及显存；无轮询、无自动模型重试。
首次加载比随后转写慢，重要词句仍需自行核对。

## 本机依赖

`.runtime/speech/config.json` 的 `python` 指向已有 quiet-recorder 虚拟环境；
`model` 指向其 Hugging Face 缓存中的完整 Whisper Turbo snapshot 目录（含 model.bin）。
当前复用 `D:/Zoom-recordings/quiet-recorder`，不更改该目录的脚本、环境、模型或会议录音。
配置不随脱敏测试副本复制，也不暴露在浏览器健康接口。
环境或模型搬家时修改这两个路径并在活动任务结束后重启 Workbench。

浏览器录音需要 localhost 或 HTTPS，以及用户允许麦克风。
旧后端不会自动加载新接口；任务结束后点左下角重启按钮，网页将刷新。

## 验收入口

`node scripts/run-tests.mjs --speech --keep`：脱敏副本，假解码器和浏览器合成麦克风，不调用聊天模型。
另设 `PHD_SPEECH_QA_CONFIG` 为本机配置绝对路径、`PHD_SPEECH_QA_AUDIO` 为合成 WAV 绝对路径，
同一入口会追加真实「浏览器录音 → 本地 CUDA → 草稿」验收。
不会使用用户真实麦克风或向助手发送消息。
