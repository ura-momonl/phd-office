# 助手工作日志

Codex、Claude、DeepSeek 的助手操作日志统一放在这里，记录执行、维护、排错等工作结果。

**按对项目的长期帮助区分两种日志。** 值得保留的实验数据、分析结果、研究判断和计划等进入项目时间线；没有这类价值的临时操作、排错、状态修复等记在这里，不因操作发生在项目内就另写项目日志。由人还是助手完成不影响归属；这里涉及研究成果时引用对应项目记录。

文件用 `YYYY-MM-DD/助手名-任务ID前8位.md`，如 `2026-10-26/codex-f3b18e07.md`；同一任务接着更新自己的文件，方便并行工作与查找。

有值得接续的结果时，几句话写清：做成什么、实际验证结果与证据位置、还剩什么。已有报告或交接直接引用，不再抄一份；普通问答不另记工作日志。

README、skill、规则文档维护各自的用法和可复用方法，任务流水账归这里。程序自动日志和原始验收证据仍在各自运行目录，科研记录仍归项目框架。

旧记录原位保留：[`CHANGELOG`](../automation/CHANGELOG.md)、[`CLAUDE-REVIEW`](../automation/CLAUDE-REVIEW.md)、[`VERIFICATION`](../VERIFICATION.md)。
