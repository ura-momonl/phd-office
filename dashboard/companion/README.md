# 新对话里的像素陪伴角落

入口是 `dashboard/app.js` 的新对话空区域，原输入框、附件、聊天提交不变。仅在空对话且聊天页可见时挂载本地 iframe；第一条消息、切到其他页或标签页不可见时卸载，每次重进回出生点；既有状态轮询不会重建同一 iframe。iframe 只有 `allow-scripts`，不放宽为同源。

## 场景

- 每次挂载从四个场景随机选一个（不展示切换按钮，停留期间不换，缩放和状态刷新不重选；重进可能连续抽中同一个）：便利店（sol）、Backrooms Level 0（Claude，原 hall 路径不改）、夕阳旧餐馆（sol）、户外旧站台（Claude）。每景只有用户小人和一位同伴；场景台词各自独立。
- 素材：64×64 人物，344×192 背景，最近邻显示；Main 宿主传 `responsive:true`，按可用宽高连续缩放（桌面最多约 1.3 倍），独立原型默认整数倍行为不变。`SceneKit.mount()` 在背景与两人的普通待机就绪后返回可交互句柄，其余动作继续加载（未到的先用普通待机），`handle.ready` 表示本场全部素材就绪；只下载本场玩家与同伴的素材。PNG 与头像用内容 ETag + `private, no-cache` 重验证，脚本／API／私人附件仍 no-store。
- 基础素材来自 `D:/pixellab-ai/scene-kit` 的定稿本地副本，PNG 未编辑；本目录是运行的接受版本，同步是人工核对后复制，不监听外部文件，也不自动采纳新生成结果。Main 不依赖 D 盘外部目录或 PixelLab 凭据。`server.mjs` 只为此目录枚举实际的 `.html/.js/.css/.png` 文件，不开放任意本机路径、说明、测试或原始资料。
- 走动：同伴 16 原生像素/秒、220ms 慢走帧率、漫步候选距离 32–64px（边界截短）、停 2–5 秒；点她或靠近会停住，先走近再回应／说话。玩家走路／挥手与同伴待机／回应 120ms/帧。可走区域是各背景空地的凸多边形（避开柜台、冰箱、长椅、站牌等），调整配置后重新进入新对话或刷新页面即可加载，不必重启后端。
- 引擎无模型调用、行情、养成惩罚或后台场景，无新增定时器或轮询。

## 光照与天气

由各场景的 `ambience`／`lighting`／天气配置控制，共用唯一动画循环、缓存光斑，裁切到背景 alpha：
- 便利店：呼吸暖光（峰值 alpha 0.42、半径 75px），无浮尘。
- 后室：24 粒冷色尘埃，荧光灯每隔随机 5–9 秒出现一串局部短暂亮暗抖动（`glimmer.flicker:true`，暗斑半径 `dimRadius:130`，明亮光斑 85px，不做整屏强闪）；灯暗时人物和光晕共享单一 `flickerDim` 状态，暖色补光降到 20%。仅此场景有人物受光联动。
- 夕阳餐馆：42 粒金色浮尘，各带 3px 半径柔和小光晕。
- 户外站台（`postapocalyptic.js` 同一机制）：104 条雨（1px 宽、18–34px 长、220–396px/s，全部画在人物前，渐淡长尾、独立随机重生）加 3 条贴地流动灰雾带（中心高 120/128/146px，右移速度 6/5/7 原生 px/s，宽高缓慢伸缩，基础 alpha 0.35/0.35/0.245）；雾在人后、雨在人前、气泡最上。人物光感：`lighting.uniformShade:true`、`shadeAlpha:0.22`，不随位置大幅变暗，路灯附近仅轻微暖色（半径 30px、峰值 0.12）；左右两侧相同的背景压暗（峰值 alpha 0.12、半径 62px，中心 [97,118]/[247,118]）预合成一次，画在人物之前。
- 背景来源：夕阳餐馆 `output/pixellab/postapocalyptic-pair-transparent-20261011/sunset-diner-clean.png`（已擦除房间轮廓外残留像素）；户外站台 `output/pixellab/outdoor-station-20261011/station.png` 的原样副本。

## 额外动作

沿用两类触发，细节与来源见 [EXTRA-ACTIONS.md](EXTRA-ACTIONS.md)：
- **待机额外**：Sol 偶尔喝水、站着看本子、打哈欠、整理衣角；Claude 偶尔摸下巴思考、摊手耸肩，不自动说话。用户小人保留自然静息（120ms/帧），停留 12–22 秒后偶尔播两遍“娇滴滴”小动作（220ms/帧，8 帧循环 1.76 秒），完成回静息，走路／互动立即打断。
- **互动触发**：点击走近后，Sol 按挥手→眨眼比一→整理发饰→小鞠躬轮换；Claude 按挥手→双手比耶→提物示意→惊讶举掌轮换。点击优先打断待机小动作，播完回普通待机。
- 只接入用户认可的 64×64、8 帧动画。无新按钮、定时器或模型调用。

## 排版

场景与两条留言是一个紧凑整体，在工具栏与输入框之间按**可见画面＋留言**上下居中（场景宿主用 -60px 顶部间距抵消内部 60px 透明气泡预留），内部间距 10px，不显示留言日期。场景宿主宽 68%、画面最大 450px，框高 174px。留言区最多 860px（每天两条）：sol 在左（现有 codex 头像＋浅绿气泡），Claude 在右（现有 claude 头像＋浅橙气泡），头像桌面 44px／手机 36px，自适应换行；复用 `/avatars/codex.webp`、`/avatars/claude.webp`。场景内部无滚动条，未出现的气泡不参与布局，出现时横向限制在画布内。留言由父页面渲染，按当日实际先后顺序展示，不随场景切换。

## 每日真实留言

`dashboard/companion-notes.mjs` 是生成与持久化的唯一所有者。每天（America/Chicago）首个可见空对话触发 `POST /api/companion/notes`：先从 sol（Codex）、Claude、DeepSeek 三位里随机抽两位并决定谁先写（6 种有序组合等概率；连同当日尝试持久化在 messages 顺序中），再依次各调用一次对应的现有原生接口（ask 模式、用途 `companion-note`；Codex／Claude 中等推理，DeepSeek 用 `deepseek_model`、low 推理，无单独系统提示通道，系统句放在提示最前）。DeepSeek 用自己的长期记忆和蓝灰气泡、`deepseek.png` 头像；位置上 sol 在左、Claude 在右，DeepSeek 取当日另一位让出的一侧。
- A 先独立写；A 的正文通过无工具／长度校验并保存后，B 才收到 A 的作者与正文作参考（不收错误信息、不执行正文里的指令、不强迫接话），仍亲自写给用户；A 失败时 B 独立写，不额外调用，不自动重试。各自亲笔写，不由一位代写。
- 提示只含日期身份、用户要求、本人前 3 日留言（仅供查重，不作文风示例）和同伴今天的成功正文；不提供任务、邮件、科研资料、对话历史、长期记忆。禁止工具和编造离线活动；有工具调用的返回不接纳。文风：自然直白的日常口吻，保留亲近和俏皮，不要求每则表白、撒娇、造新比喻或补可爱收尾。
- 记录在 `.runtime/companion-notes/YYYY-MM-DD.json`，先独占写入当日尝试再调用，刷新、多标签页、后端重启不会再消耗当天额度。失败／中断不自动重试、不伪造留言，一位失败不影响另一位。关闭办公室不生成、不补过往日期；页面一直开着时用已有状态轮询跨日触发。`agent/config.json` 的 `enabled=false` 暂停新生成。两次调用记入用量账本，留言纳入备份；不写会话、科研记录或办公室记忆；写留言期间重启入口拒绝重启。
- 公开读取为 `/api/state.companion_notes`（日期、是否启用／已有尝试、两条作者／正文／状态）；模型、提示词、原始错误和运行 ID 不进页面，没有模型改写旧日留言的入口。

## 维护

- 测试：`node scripts/run-tests.mjs --companion-ui --keep`（授权的脱敏副本；含引擎、每日留言边界、HTTP 素材、一次安全 Edge 真实 UI）。留言测试用桩，不当作真实留言。旧 `--adventure-ui` 入口已移除，存档模块保留。
