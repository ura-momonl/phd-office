# 主题接口（配色与字体）

颜色集中定义在 `theme.css` 顶部的 `--c-*` 令牌里；默认值就是原来的界面，所以不选任何配色时外观不变。
`theme.js` 只负责“用户选了什么”：写 `<html data-palette="…" data-font="…">`，选择存在浏览器 localStorage（键 `office-theme`），在 设置 → 外观 里改。

## 发现一块颜色还是老的，怎么接进去
1. 在 CSS 里找到那条写死色值（`#xxxxxx`、`rgb()`）的规则。
2. 在 `theme.css` 里找语义最接近的令牌（页面/面板/边框/文字/强调/状态色/侧栏）；没有就加一个，默认值填原来的色值，界面不变。
3. 把规则里的色值换成 `var(--c-xxx)`。
4. 常见坑：同一个选择器可能在 `style.css` 和 `workspace.css` 各有一条，**后加载的才生效**（侧栏就是这样）；改的时候两处都看。带过渡动画的元素换配色后要等一下才变色。

旧变量名（`--bg --panel --border --text --muted --green --accent --red --amber --violet --blue …`）已经指向令牌，用它们的规则不用改。

## 新增配色
在 `theme.css` 里加一块 `[data-palette="名字"]{ --c-accent:…; --c-bg:…; … }`，只写要变的令牌；再在 `theme.js` 的 `options.palettes` 加 `['名字','显示名',[三个色块]]`。配色行在只有一个配色时不显示，加到第二个就自动出现。
先别急着开放：只要还有写死色值的块，换配色就会出现新旧混搭。以 `[data-palette]` 块临时试，看哪些块没跟着变，再按上面的步骤接入。

## 字体
`theme.css` 里 `--font-*` 是字体栈，`html[data-font]` 决定用哪个；不选就是原字体。新增一种：加一条 `--font-名字`、一条 `html[data-font="名字"]` 规则，再在 `theme.js` 的 `options.fonts` 里登记。

## 当前接入范围
已接入：页面/面板/边框/文字/强调色及状态色（旧变量别名）、左侧栏（含各页导航色）、交接摘要、主按钮与发送按钮的强调色。
其余模块（日历、项目、文献、仪器、邮件等）仍有各自写死的色值，约五百种，按需逐块接入。
