# 课题办公室

双击 [Open-Workbench.cmd](Open-Workbench.cmd)，或打开 http://127.0.0.1:18787 。本机工作台现在可以直接启动 Codex、Claude Code 完成明确提出的任务。原 OpenClaw 的后台与自启保持关闭。

## Windows 后台与托盘

- 当前用户登录后，`PhD-Workflows.lnk` 隐藏启动同一后端与绿色「课题办公室」托盘图标，不自动打开浏览器。图标可在右下角 `^` 中找到；位置由 Windows 管理。
- 双击图标或右键「打开办公室」打开页面；重复启动不会新增托盘或后端。菜单显示健康状态，后端不可用时可选择「启动后端」，日志在 `.runtime/dashboard`。
- 「退出办公室（停止后端）」会检查活动任务；任务未结束或无法确认后端身份时拒绝停止。打开页面沿用源码更新检查，只有没有活动任务时才刷新旧后端。
- 安装／恢复登录自启：`powershell -NoProfile -File dashboard/Install-Startup.ps1`。关闭自启：同一命令加 `-Uninstall`，不会停止当前后端。这里是当前用户**登录后**启动，不是未登录的系统服务。
- `dashboard/Start-Dashboard.vbs` 是统一隐藏入口（加 `open` 可同时打开页面）；旧 `scripts/Install-Startup.ps1` 属于 OpenClaw，不使用。空闲托盘只做本地健康检查，不新增模型调用、自动重试或外部发送。

## 开始使用

- 侧栏「对话」旁的数字只计正在执行的助手任务，不含用户自己的实验等进行中事项；顶部执行提示采用同一口径，工作看板仍保留全部进行中事项。已在对话模块时，再点侧栏「对话」可依次切换助手正在运行的会话（包括任务会话，同一会话只跳一次）；没有可跳转的会话时保持当前对话，输入草稿保留。
- 对话支持把文件拖到聊天区域，或点击输入框左下角附件图标选择多个文件；发送前可移除，发送后可从消息下载。每条最多 10 个普通文件，单个 20 MB、合计 30 MB；图片另计，最多 4 张、单张 6 MB、合计 12 MB，仍可 Ctrl+V 粘贴截图。附件保存在本机，助手得到可读取的路径；不自动归档到项目。
- 对话中的本地文档／图片链接，在本机普通点击交给 Windows 默认软件打开；Ctrl+点击或中键仍在浏览器预览／下载，手机端也保留预览／下载。文件夹用资源管理器；脚本、程序、快捷方式、宏专用格式（如 `.docm`）及未知类型不走默认软件入口。这是扩展名限制，不是文档内容安全扫描；默认软件按自身规则处理内容。系统返回关联或启动错误时会显示，不自动安装或改关联。旧 `/workspace/...` 链接兼容读取，仍检查路径越界和敏感文件；助手发新链接用绝对本地路径或相对 `/api/local-file?path=...`，不要写死 localhost 地址。附件下载规则不变。后端须空闲重启、页面刷新后生效。

- 在对话中说明要做的事，可用 `@Codex`、`@Claude` 指定对象；`@all` 固定为 Codex 提案、Claude 核查、Codex 合并三轮。无需填写负责人或任务类型。
- 两位助手回复中的 `powershell` / `pwsh` / `ps1` 代码块可点「运行 ↗」：核对命令及起始目录后确认，弹出普通 Windows PowerShell 5.1 窗口（不是 PowerShell 7），在窗口看输出、交互或 Ctrl+C 停止。起始目录默认 `D:\Main\assistant`，可改为其他已存在的绝对目录；完整路径和命令中的 `cd` / `Set-Location` 原样执行。不自动提权、不绕过脚本策略、不自动重试；「已启动」不等于命令成功。窗口以当前 Windows 用户运行，并非助手文件沙箱。功能须空闲重载后端才生效；用户消息及项目资料中的代码保持只复制。
- 在「周计划与复盘」每行写一个本周目标，保存后点击「推进这件事」。主要工作来自周计划；邮件与杂事放在附带清单。
- 「项目」概览显示整体进度和当前步骤；详情按阶段、子步骤、任务逐层展开，展开状态在刷新后保留。当前项目计划是用户授权的占位示意，明确标注，不进入真实复盘。任务输入、交付和验收依据按需展开。
- 「收件箱」按审批、验收、判断分组，组内按紧急程度排序；旁边显示交付摘要、五分钟撤销和实际验收记录。撤销只恢复本地处理标记，不发送邮件。普通本地读写直接执行，科研交付保留验收依据。
- 收件箱卡片左上角标事项类型，标题、具体问题和按钮由 AI 的 inbox.json 描述。reply 按钮将用户选择交回 agent，review 打开依据，accept 记录确认；不固定为发送与编辑。选择记录保留在会话中，取消后可回到原问题。生成卡片与正常工作共享一次模型执行，渲染不调用模型。模板见 [inbox-card.example.json](workspace/templates/inbox-card.example.json)。
- 每周一 09:00（America/Chicago）由程序生成上周复盘、本周计划和组会 Markdown 提纲。停机时会在下次运行补生成；尚未自动制作 PPT。
- 周复盘同时汇总「办公室改进」：实际生成交付、当前待验收、失败或中止任务和模型调用，并按记录提出简单改进建议，不统计工时。

## 已连接和边界

两位助手派出的子 agent 按主助手轮次收进一张默认折叠的总卡片，标题显示“已完成 x/y”，并单列运行中、失败和已结束数量；展开后保留各子 agent 的小卡片、过程、结果和来源标记，不再逐条铺进主聊天。无法确认独立身份的旧记录只作历史记录展示，不计入子 agent 数量。旧的已标记子 agent 发言也按历史记录收起；未记录的任务说明不补造。子 agent 原始发言不额外拼进后续主聊天历史，原生结果回传照旧，主助手仍负责最终回复。界面刷新可加载展示改动；后端空闲重载后，新工作轮使用更新的归属记录和历史筛选。

Codex 原生 app-server 和 Claude Code 已分别通过一次实际文件交付、一次实际对话检查。每个任务使用短会话，界面会保留结果与最近相关消息，不向模型重复发送全部历史。执行与用量记录见 [.runtime/diagnostics/native-validation.json](.runtime/diagnostics/native-validation.json)。

学校 Outlook 已连接。Windows 任务 `PhD-Workflows-Mail-ReadOnly` 每十分钟增量读取、去重和更新本地清单，收件不调用模型。邮箱唯一活跃账本为 `.runtime/mail-flow/mail.sqlite`。工作台判断新邮件包，仍不能发送或修改邮箱；两位助手按用户对具体操作的授权，共用 `mail outlook-tools [工具名]`／`mail outlook <JSON文件>` 操作当前连接器，不限草稿、不强制先建草稿后发送。入口、真实限制和确认要求见 `help mail` 与 [mail-flow/README.md](mail-flow/README.md)。不自动对外联络或下单。

Codex 账号额度来自原生只读接口；Claude 的每次调用用量自动记录，账号剩余额度暂时需要从官方 Usage 页面记录。助手账本只统计通过本框架启动的调用，不能代表其他 Codex/Claude 会话的全部消耗，token 数也不能换算成固定订阅额度或美元费用。空闲、查看页面、收件、日期检查和周材料生成不启动模型。

[Discord 入口](remote/README.md) 已沿用同一个执行器，待本地机器人与频道配置及真实收发验收；无需暴露公网 MCP。桌面 UI 已检查，手机版本暂不开发。

五个项目入口与文件夹已建立，目标和材料可以逐步补充。采购、文献和软件模块保留可扩展入口：报价比较保留缺项；文献支持 DOI 元数据和校园全文入口，校园登录、真实全文下载、Zotero 桌面连接仍待验收。AutoCAD、COMSOL、Fusion、Altium 的固定工程目录与连接方式已登记，本轮没有操作工程或执行仿真。

目录安排见 [BOOTSTRAP.md](automation/BOOTSTRAP.md)，扩展入口见 [automation/README.md](automation/README.md)，短会话与双 AI 协作见 [AI-COLLABORATION.md](automation/AI-COLLABORATION.md)。助手工作日志与验证结果统一从 [logs/](logs/README.md) 进入；[VERIFICATION.md](VERIFICATION.md) 保留旧验收入口。
