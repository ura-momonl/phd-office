# Keithley 6221 本地控制前端

运行 `python control_6221.py`，或在办公室 **更多 → 仪器图鉴 → Keithley 6221** 点击 ▶ `control_6221.py`。测量电脑需要 Python（含 Tkinter）、PyVISA 和已有 IVI/NI-VISA。复制使用时将 `control_6221.py` 与原 `Keithley6221.py` 放在同一目录。

如需指定已有的 VISA 库：`python control_6221.py --visa-library "C:\Windows\System32\visa64.dll"`（以本机实际路径为准）。不安装或修改系统驱动，不回退到 pyvisa-py。

## 使用

1. 刷新/手输 VISA 地址；默认 `GPIB0::12::INSTR` 仅是旧程序地址。连接只查询身份与 `OUTP?`，不调用会复位的原 `connect()`，不发送 `*RST`、`*CLS`，不改变原输出。非 6221 身份拒绝控制。
2. 根据样品核对本次最大绝对电流与 compliance。默认上限 1000 µA、compliance 1 V **不是任何样品的安全保证**。
3. DC 支持正负电流。正弦 AC 支持峰值、DC 偏置、频率。所有电流输入单位是 **µA**，内部转换为 A；AC 幅度是 **峰值 Ipk，不是 RMS**。只有确认开启对话框后才改变输出。
4. AC 沿用原驱动：最佳量程、Phase Marker 输出 Trigger Link Line 1、持续 999999 s。运行中更新仅改幅度/偏置，不中断波形；改频率或 compliance 请重新配置开启。
   2026-10-13 用户批准：前端每次重新配置开启 AC 时，在关闭输出/解除武装后、原波形配置前发送 `SOUR:WAVE:EXTR OFF`，明确让 **6221 自行启动波形、不等待外部启动触发**。这不关闭 Phase Marker，同步仍从 Line 1 输出；锁相保持 External，前端不改锁相设置。新增指令依据官方手册 §7-31。连接和运行中调幅都不发送这条指令；已运行的旧窗口需退出后重新打开。
5. 停止会尝试 ABOR、独立发送 OFF、回读输出。退出先停止并断开；关闭未确认时保留窗口和会话。通信失败可能使仪器继续输出，必须检查面板。停止请求等待当前 VISA 命令结束，**不是硬件紧急停止**。

## 边界与依据

- 原 `Keithley6221.py` 不改。DC、AC、同步与运行中更新的指令由原实测驱动定义；前端仅包裹确认、单位转换和限制。
- 状态是 `OUTP?` 的按需回读，不是电流/电压实测；没有后台硬件轮询、自动重试、扫描、数据采集或 2182A 联动。
- 每次读取错误队列只取一项。开启前后各检查一次；已有错误阻止开启。操作中失败尝试关闭输出，不自动重发设置。日志仅留窗口，不写测量数据。
- 不与其他程序同时占用仪器；也不能阻止其他程序或面板改变状态。窗口状态只代表最近一次回读。
- 新增查询和输入范围参考 [Tektronix 6220/6221 Reference Manual](https://download.tek.com/manual/622x-901-01%20(C%20-%20Oct%202008)(Ref).pdf)，14-6、13-10、7-3：OUTP?、SYST:ERR?，频率 1 mHz～100 kHz、电流峰值不超过 105 mA、compliance 0.1～105 V。幅度+偏置还需符合本次电流上限；具体精度与可用范围由仪器状态决定。

离线测试通过办公室脱敏副本入口运行：`node scripts/run-tests.mjs --instruments --keep`。测试替换 VISA 资源工厂，执行真实原驱动和真实 Tk 控件，绝不打开仪器。
