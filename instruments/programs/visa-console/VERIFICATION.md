# 验证记录（2026-10-11，America/Chicago）

## 做了什么

新增 `visa_console.py`，Tkinter 小窗口，单个后台线程顺序执行 VISA 操作：列出资源、连接/应用通信参数、查询、发送、读取、断开。显式选用 IVI 后端，调用已有 VISA 库；没有驱动安装/更新、注册表、配置文件或环境变量写入，也没有自动识别、仪器复位或输出设置命令。

仅刷新才列资源，连接后也不会自动发送 `*IDN?`。关闭软件只断开会话，不改变实际仪器输出。通用文本控制台，不是 NI MAX 的驱动管理/全硬件发现替代品。

## 实际验证了什么

正常授权命令：`python -W error software/visa-console/test_offline.py`。

结果：**10 项通过，退出码 0，无警告**。真实应用代码复制到临时隔离目录，PyVISA 的 ResourceManager 被模拟对象替代；Tkinter 使用本机原生隐藏窗口，不占用鼠标键盘。未打开真实 VISA 后端或仪器会话。

- 导入/窗口初始化不打开后端或仪器，刷新使用 `@ivi` 与 `list_resources('?*')`，资源枚举不发送仪器命令。
- 显式 DLL 路径仍使用 IVI，没有 pyvisa-py 自动回退。
- 连接、串口波特率、独立读/写结束符、超时应用；GPIB 不写串口波特率。
- 查询、发送、单独读取各执行一次，NUL 等隐藏字符在日志中可见；超时不自动重发。
- 错误参数/未连接时不打开设备、不发送命令。
- 原生隐藏窗口的按钮完整流程、响应/错误日志和断开功能。
- 查询进行中请求退出，会等待当前操作结束再关闭会话，不并发关闭；关闭不发送 `OUTP OFF` 或任何隐式输出指令。
- 仪器会话关闭失败时仍尝试关闭 ResourceManager。

另外实际运行 `python -W error software/visa-console/visa_console.py --help`，退出码 0，无 VISA 初始化。

环境已有 Python 3.14、Tk 8.6、PyVISA 1.16.2；本轮没有安装或更新依赖。

## 没验证什么

未对真实 NI-VISA 库或真实设备执行资源枚举/连接/命令。测量电脑上现有 NI-VISA 的可用性、实际加载的是哪家 IVI 实现、实际 VISA 资源、终止符与命令适配仍需现场验证。多厂商共存时应看刷新日志中的实际 VISA 库，必要时为这次运行指定已有 NI DLL 路径；不改全局配置。

测试覆盖了原生隐藏窗口事件与控件，没有人工可见窗口视觉验收或真实硬件通信验收。软件不是精确识别每个 USB 设备的扫描器；串口资源存在不证明接有仪器。
