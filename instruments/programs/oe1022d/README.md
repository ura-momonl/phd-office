# Lock-in 窗口读取与控制

## 窗口版：read_lockin_ui.py（二倍频 + 三倍频同时读取 + 设置）

图鉴点击 ▶ `read_lockin_ui.py`，或 `python read_lockin_ui.py`（只需 tkinter、numpy、PyVISA 与已有 NI-VISA/IVI；不 import 主驱动，因为其构造函数会写 Ch2；可加 `--visa-library <DLL 路径>`）。默认地址 ASRL4::INSTR，串口 9600、读写 CR、2000 ms。没有曲线，只直接显示数字。

**读取（左侧）**：在**同一个通道**里同时读两个谐波检测槽“谐波 1”“谐波 2”，每个都显示 R（自动 V/mV/µV/nV）和 φ（度）大字，以及最近 N 点（20/50/200/全部）的均值、σ、最小/最大和原始值（φ 用圆周统计）。一次 `SNAPD? <通道>,7,8,11,12`（Rh1、φh1、Rh2、φh2，驱动参数表的 7、8、11、12）同一时刻读出，所以两个谐波互相同步。卡片标题按回读的谐波次数显示，如“谐波 1 · 2 f”“谐波 2 · 3 f”。
- 把谐波 1 设为 2 次、谐波 2 设为 3 次：设置面板里点“谐波 1 = 2f，谐波 2 = 3f”（写 `HARMD i,1,2` 和 `HARMD i,2,3`），或在两个“谐波次数”框里分别输入。k × 参考频率超过 102 kHz 时仪器会自动调小，窗口会提示回读不一致。
- **读的是谐波槽，不是基波 X/Y/R/φ**。`SNAPD?` 最多 5 个参数，4 个谐波参数加基波的 R、φ 放不进同一次查询，所以不读基波。
- 暂停/继续（空格键）、清空、通道 1/2（只在暂停时可换，换通道清空读数）、手动保存 CSV（time_s、timestamp、R_h1_V、phi_h1_deg、R_h2_V、phi_h2_deg、channel；文件头 `#` 行记录谐波次数等设置和各次改动时刻，读时忽略 `#` 行，pandas 用 `comment='#'`）。连接和读取只发 `*IDND?`、`SNAPD?` 和各设置的 `?` 回读，**不写入仪器**。

**设置（右侧面板，当前通道）**：只包含主驱动 `SSI_OE1022D_modified.py` 里已有的设置指令，写法照驱动：

| 控件 | 命令 | 说明 |
| --- | --- | --- |
| 参考来源 外部/内部 | `FMODD i,j` | 驱动只给原始数；0 = 外部、1 = 内部取自你的程序（内部 = 1）与手册。读回 2 显示为“内部扫频” |
| 参考频率 | `FREQD i,f` | 1 mHz～102 kHz；外部参考时只读，显示测得值 |
| 谐波 1 / 谐波 2 次数 | `HARMD i,1,k` / `HARMD i,2,k` | 整数 1～32767；受 k·f ≤ 102 kHz 限制，仪器可能改小，会回读显示 |
| 相位 | `PHASD i,x` | −180°～180° |
| 灵敏度 | `SENSD i,n` | 28 档，表取自驱动 |
| 时间常数 | `OFLTD i,n` | 18 档，表取自驱动（0 起始：10 = 1 s、11 = 3 s） |
| 滤波斜率 | `OFSLD i,n` | 0/1/2/3 = 6/12/18/24 dB/oct（手册） |
| 同步滤波 | `SYNCD i,0/1` | 关/开 |
| SINE OUT 幅度 | `SLVLD i,x` | 0～5 Vrms；会改变加在样品上的激励，写入前弹窗确认；不动 `SVLLD`/`SWVTD` |
| 自动相位 / 自动增益 | `APHSD i` / `AGAND i` | 弹窗确认；通信等待放宽到 30 秒，完成后回读全部设置 |

- **时间常数下标与手册相差 1**：手册从 1 起（11 = 1 s），驱动从 0 起；你 10-11 实测程序发 11 时仪器是 3 s，与驱动一致，故按驱动。下拉项方括号里是实际发给仪器的下标，请与面板对照。
- 每次写入后立即回读该项，一致才显示“已回读确认”，否则红字提示以面板为准；改动时刻记入 CSV 文件头。
- 没有放入的设置：输入方式（主驱动只实现差分 A−B 一个值）、参考触发沿、输入接地/耦合、陷波、动态储备、扫频、数据存储、SINE OUT 的 SVLLD/SWVTD 等。
- 通信出错或读数格式异常（必须正好 4 个数）：停止、关闭会话、不自动重试，状态栏显示原因；最后一次写入是否生效请看仪器面板。关闭窗口/断开只关会话，不改仪器输出。
- R 的单位按你现有扫描程序取 V。离线用假 VISA 测试，**未连真机**。
