# 实际粗处理的留存与总数据展示规范

核心是用户2026-10-28的原话：**“agent自己做了什么粗处理就得放什么上去。”** agent根据研究任务和实际数据自主选择处理方法；本规范规定的是实际处理结果怎样完整留存、怎样与原始数据对照展示，不替agent预定要算哪些东西。已经做过的每一种粗处理，包括以后新增的类型，都进入同一条原始数据→实际处理阶段→可展示结果的路径；没有做过的处理不冒充已有结果。本次只定规范，不处理数据或实现HTML。

用户提供的三张截图给出总数据浏览与常见粗处理的完整展示参考，下面以其中按温度、驱动、方向／接线和通道成组的纵横向1–3阶锁相信号说明。图中的归一化、扫描支平均、相位、几何因子g、误差和局部指数是示例，不是允许展示的处理白名单，也不是所有数据都要预做的算法。HTML或其他交互形式展示原始数据及实际粗处理，不是研究结论的总报告。

## 1. 处理agent实际做过的粗处理都留下共享结果

随着实际处理保留原始输入、每个已执行阶段的结果及其来源。相位参考、窗口平均、校准、归一化、分支配对等若实际做过，就能分别对照处理前后；以后做了其他类型的粗处理，也以它的实际名称、输入输出和参数进入展示，不必先修改本规范取得一个“允许的类型”。

下面的对应表解释截图中已有处理需要呈现什么，并不要求agent为填满界面而额外计算：

| 实际做过的处理示例 | 共享结果与展示保留的信息 |
|---|---|
| 列映射、单位转换、接线整理 | 原始列与读出通道的对应、实际换算和接线来源；可对照原始标识与处理后标识。 |
| 平台／窗口平均与有效读数处理 | 各通道使用的原始行区间、窗口、代表值、SD／SEM及有效读数数目。 |
| 扫描支识别、配对和平均 | 各原始分支、实际配对条件和权重、分支各自结果及平均结果；保留其他重复的入口。 |
| 比值／系数归一化 | 分子分母原量、参考通道、幂次、计算顺序、单位和实际传播的误差。 |
| 相位参考、复投影或符号处理 | 原始幅值与相位、实际参考／变换及其依据、处理后的复信号或带符号分量。 |
| 几何、接触或其他比例校正 | 校正前后数值、实际因子及定义、构型、来源与所用误差。 |
| 局部驱动依赖描述 | 当前量的局部指数、实际驱动窗口、点数和扫描支。 |
| 条件匹配、代表选择、排除或映射 | 实际匹配与选择、原始记录去向、具体原因及源文件；直接测量和映射显示分别可查。 |

粗处理与显示用同一份结果：各实际阶段保留源文件与行区间、测量条件、处理名称与定义、参数、输入／输出及现有误差和标记。沿用处理脚本与已有输出组织这些关系，不为展示再维护一份平行结果；后续分析与浏览器读取同一份结果，按相同定义选择阶段或切换已有处理版本。新增处理阶段随结果可见，页面不靠固定的几种按钮决定哪些处理值得展示。未计算的项目显示其实际状态，不画虚假的系数、误差棒或局部指数。

### 原始记录、粗处理点与展示选择的关系

- 原始层保留各文件、全部采样行、时间／次序、实际驱动与温度、通道读数和相位、仪器设置及来源。重复测量、短记录、不完整扫描都能打开；文件副本与独立重复有不同标识。
- 粗处理点能回到原文件与行区间，携带接线、温度、驱动、扫描支、所用窗口、实际读数数目和离散度。稳态窗口、单位换算、相位参考、几何校正与符号约定来自这批测量，并在工具里可查看。
- 展示层可以选代表扫描、隐藏某类点或折叠方向，但原始层与全部粗处理表仍在。当前视图写明用了哪些记录、哪些没有进入此图；从标记或文件表可打开它们。展示选择不改写原始数据。

## 2. 截图要求覆盖的三个总览

这些总览显示原始数据及实际产生的处理结果。处理阶段选择来自本批数据真实存在的阶段与版本，可把原始量、任一中间结果和处理后结果并排或叠加对照；新增粗处理类型也进入这里，不只显示下面举例的幅值与系数。未做的处理保留真实状态，不为了点亮按钮临时补算一套结果。

### A. 每个温度一行的方向响应

每行并列四幅图：**纵向二阶、纵向三阶、横向二阶、横向三阶**。横轴按同一方向／电流接线顺序排列，轴标签或其邻近位置同时给出电极进出名称，不能只有角度。每行有独立电流滑块和当前数值；另有“所有温度一起设为……”的联动滑块，可在联动后继续单独调整一行。每行显示实际有数据的方向数及代显数。

上方的共同控制项覆盖：

| 控制 | 可切换的内容 |
|---|---|
| 实际处理阶段 | 原始量、实际做过的各中间阶段与处理版本；能查看其输入、参数和来源 |
| 纵轴量 | 原始谐波幅值；归一化系数（本例二阶V₂ω/Vaa₁ω²、三阶V₃ω/Vaa₁ω³） |
| 扫描方向 | 上扫、下扫、平均、上下扫分开 |
| 误差棒 | 标准差SD、标准误SEM；当前定义与读数数目可查 |
| 纵轴 | 线性、对数；零和负值仍可在相应的带符号／线性视图查看 |
| 纵轴范围 | 随当前电流重新缩放；固定范围以比较滑块前后变化 |
| 构型 | 全部构型；每个方向一个代表构型，代表选择可查 |
| 超量程／存疑点 | 显示并加标记；仅从当前图隐藏，可一键恢复 |

同一方向有多个构型，或上下扫分开时，允许轻微像素错位以分辨点，实际角度不变；不同温度仍共享相同方向坐标，不把温度颜色画成不同角度。上下扫分开用深／浅色区分（图中深色上扫、浅色下扫），以细线连接同一构型、温度与电流的对应点。其余连线只连接所说明的同一构型与扫描支。

### B. 所有温度叠加的方向总览

- 可切换纵向Vaa／横向Vab，及一阶、二阶、三阶、二阶归一化系数、三阶归一化系数、几何校正的一阶V₁ω/g。
- 共同电流滑块、当前数值和单位，与线性／对数纵轴。温度用一致的颜色及图例表示。
- 所有温度画在同一组方向位置，缺测留空。总览提供“每个方向、每个温度的最新可用扫描”代表视图，也能回看其他重复与代表选择依据。
- 一个方向一个连线点的视图可按已说明的直接输入、读出几何等优先关系选代表；其他构型仍可显示为独立标记。不能把“代表点”误称为全部测量。

### C. 每个方向的温变小图

- 每个方向／接线一张小图；标题同时给方向约定和实际电流进出电极。横轴温度、纵轴当前选择的量，跟随总览的通道、谐波、驱动和坐标选择。
- 不同小图共用相应纵轴范围，便于比较方向；温度颜色与上图一致，形状表示相应读出构型，灰线只连同一构型的温变。
- 温度刻度保持可读，不让密集刻度叠成一团。方向数、温点数和面板布局随数据变化。

## 3. 截图中粗处理示例的计算含义

以下解释截图中粗处理的计算含义，便于实际采用这些方法时保存准确的结果并展示。它们不是agent开工前必须逐项执行的流程；采用其他方法时同样展示实际做法和结果，不受这些例子限制。

### 平台、扫描支与平均

实际采用平台／扫描支处理时，按采集次序保留识别出的恒驱动段及每一支，不把原始分支覆盖为平均曲线。平台均值和离散度使用已说明的窗口，保留到完整逐点记录的关联。上／下扫的“平均”只组合相同接法、温度与可比驱动的点，保存实际匹配值和支数；采用等权支平均还是按独立读数加权，在计算定义里说明。分支平均的误差按其实际权重传播。驱动网格不一致时保存实际匹配规则，不把未测的驱动点悄悄补成实测。

相位参考或复平均若被采用，保留按当前测量约定生成逐点复信号、再求所选分量／复均值的实际过程。若本次采用复信号处理相位绕回，展示该步骤及其结果；原始相位始终可看。本例用户给出的参考为`phase_channel − phase_Vaa_1ω`；这是测量约定，不推广为所有锁相数据的固定参考。

### 幅值、系数和几何校正

- “原始幅值”与带符号投影／复分量分开命名，不能用绝对值替掉带符号结果而仍沿用原标签。
- 归一化系数明确写出分子通道、分母参考通道、幂次和单位。本例Cₙ=Vₙω/Vaa₁ωⁿ；横向高阶也使用已指定的一阶纵向参考。计算顺序（平台均值后取比值，还是逐点比值后平均）随视图说明并保持一致。
- V₁ω/g展示保留原一阶量，并写明g的定义、几何／接触构型和取值来源。不同构型不能共用一个未经说明的g。

### SD、SEM与误差传播

- 各通道各自使用自己的读数计算离散度；横向误差棒不套用纵向通道的离散度。
- SD表示所选读数的散布；SEM=SD/√N_eff，N_eff是实际独立更新数，不是导出行数。锁相更新慢于采样、相邻行重复同一读数时，按仪器更新／采样信息识别有效读数，并能查到处理方式；“约两次采样更新一次”是截图这次采集的说明，不固定成所有数据都除以2。
- C=A/Bⁿ的独立误差近似为`σC²=(σA/Bⁿ)²+(n·A·σB/Bⁿ⁺¹)²`；因此系数误差包含谐波读数和一阶分母读数两部分，不能只给分子误差。截图使用独立误差合成，这一假设随结果说明；有协方差资料时按实际协方差传播。复分量或带符号投影按对应变量的雅可比传播，不把相位误差混成幅值SD。
- g作为已知比例时，V/g的误差随同缩放；若使用g的不确定度，则一并传播并说明来源。分母接近零时保留原读数并显式标识该归一化点，不以溢出值冒充正常系数。

### 局部电流幂指数

局部幂指数若被计算，含义是对实际电流窗口中正驱动与非零幅值作`p=d log|signal|/d log I`的局部拟合；保存窗口、点数和所用扫描支，供悬停查看。原幅值与系数各按自己的当前量计算；理想I²／I³幅值的p分别为2／3，相应理想常系数的p为0。截图的±0.1 μA是一个窗口示例，窗口与单位由当前数据给，不写死。不能取对数或窗口点数不足时保存实际原因与原点，而不是填一个指数。

## 4. 构型、疑点与映射的可视标识

- 图例能区分最近邻读出（圆）、次近邻读出（方）、其他读出构型（三角）；短接输入用空心标记；存疑文件或当前超量程点加虚线圈等附加标记。横向面板的形状仅用于区分其对应构型，不能因纵向构型分类就宣称横向也属于同一种几何校正。
- 超量程条件来自仪器量程与实际单位，可按一阶纵向或横向读数标记并显示／隐藏。截图的“Vaa或Vab一阶>1 V”是该量程示例，不是通用材料电流阈值；量程参数可替换。
- 若展示采用源漏对调θ↔θ+180°的折叠／代显，虚空心等标记区分**直接测量与映射显示**；标题和悬停给出原角度、实际接线、原文件及采用的坐标／符号变换。可切回只看直接测量，映射不是给原始表新造一份测量。
- 悬停同时给出文件、温度、实际电流、电流进出电极、纵横读出对、构型、扫描支、原始／映射状态、当前值与误差、局部幂指数。点开能查看原始行和粗处理窗口。

## 5. 重复记录、排除与存疑的去向

工具有“排除和存疑的文件”表，至少包括文件、状态、温度、构型、具体原因及打开原始记录的入口。被当前总览排除或隐藏不等于删掉原文件；存疑文件可以继续画出并加标记。早期独立重复仍可从文件表／重复选择器和完整导出表查看，代表扫描的`primary`状态可见。导出能区分原始值、粗处理值、展示选择与映射来源。

## 6. 从共享结果到展示

把数据格式／列映射、测量约定、实际粗处理与界面展示分开。驱动与温度网格、方向数、接线名、通道、处理阶段及其参数、误差与代表选择来自当前测量和实际执行结果；展示层据此呈现原始→各实际处理阶段的对照，并组织相应的总览与交互。换批数据复用这一关系，不把某套处理方法或科学假设写死进展示器。

[现有分组信号查看器](grouped-signal-explorer.md)提供可复用的打包、原始行、分组切换和抽稀机制；制作总数据浏览工具时，在这些基础能力上完成上述三个总览、粗处理控制和记录追溯。浏览工具展示原始与粗处理，研究结论与复测建议另存报告。
